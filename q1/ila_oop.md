# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
It can be used by making a class named Product to store the product name, price, quantity, and its properties to make it more organized, efficient, and convenient when it comes to information about the product.

### 2. Abstraction
It can be used to give the user simple outputs and hide the complex process. For example, using sellProduct() can automatically check the available stock and update the inventory without the user needing to know how it happens.

### 3. Inheritance
It can be used to add categorizations based on the class to inherit the properties. For example, by creating new product types like FoodProduct, DrinkProduct, ApplianceProduct, they now inherit the properties of the parent class like the product name, price, quantity, and properties.

### 4. Polymorphism
It can be used to allow different products to respond to the same method, but different behaviors. For example, products Food and Appliances can both be displayed using displayInfo() but their information can be shown in different ways. This allows the code to be more flexible.
