# SG4 - Understanding Classes and Objects
## Steam 
## A collection of games from the gaming platform, based on the game type you like best. 
|   Property   | Data Type |                    Description                     |
|--------------|-----------|----------------------------------------------------|
|Game name     | String    |Name of the game                                    |
|Developer     | String    |The one who made/developed the game                 |
|Amount of bits| Integer   |The amount of bits the game needs to be installed   |
|Game Type     | String    |What kind of game                                   |
## Methods
| Method |                                 Description                                   |
|--------|-------------------------------------------------------------------------------|

|play()  |It tells the game to run to be played by the user                              |
|save()  |It tells the game to be saved into a file during an important progress point   |

## Design Explanation
### Why did you choose this class? 
Because gaming has been helpful to me whenever I get stressed or just to pass the time. It also taught me several life skills like patience, determination, and strategy. 

### Which property is the most important? Why?
The most important property is the amount of bits, because bits are stored in the RAM which is needed to run the game through the files. If I want to install a lot of games, organize your game file sizes.

### Which method is the most useful? Why?
The most important method is play because if you cant play the game, then what is the point of buying or installing it?
